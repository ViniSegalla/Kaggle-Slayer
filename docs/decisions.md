# Technical decisions

1. **Typed orchestration over LangGraph.** An LLM coordinator and four specialist roles collaborate through validated actions and durable state. A single scheduler owns state and budgets; independent specialist calls and numerical experiments can run concurrently within resource limits.
2. **Agentic CLI by default.** The CLI loads `configs/agentic.yaml` and requires a configured live or local LLM endpoint. Agents choose experiments and follow-up work; Python enforces validation, resource limits and upload authorization. Deterministic execution remains an explicit compatibility mode, and scripted integration examples run offline without provider credentials. Provider failure in agentic mode records an incomplete outcome rather than falling back.
3. **SQLite plus structured files.** SQLite serves the dashboard and resume logic; JSON snapshots and JSONL make runs inspectable without the app. Atomic file replacement avoids partial JSON reads.
4. **One isolated worker per experiment.** A real wall timeout can stop a stuck model. Estimator thread counts are capped. This is isolation for reliability, not a sandbox for executing untrusted code.
5. **Model-specific preprocessing.** CatBoost uses native categorical inputs; other trees use unscaled encoded features, while linear models use scaling. Fold-fit transformations prevent validation leakage. Supported agent-selected preprocessing and feature operations are recorded in each experiment's training contract. Category limits and an estimated-cell memory guard bound preprocessing size.
6. **Full-data refit per completed experiment.** More fitting work than refitting only the winner, but reliable final output after later timeouts. Only training data enters the refit.
7. **Conservative integration scope.** Single train/test CSV relationships, one target, label/value or class-probability templates. Ambiguities require YAML. Images, text-model tasks, notebook-only competitions, arbitrary relational joins and ranking tasks are unsupported.
8. **One upload per run.** Explicit CLI consent, persisted intent and no retry prevent duplicate uploads after uncertain network responses. Follow-up feedback is read-only. Kaggle enforces account quotas and competition eligibility; no mechanism bypasses rules.
9. **uv dependency and runtime workflow.** `pyproject.toml`, `.python-version` and `uv.lock` describe the environment. CatBoost and XGBoost are core dependencies. The agentic profile allows six model families and at most eight experiments, with no mandatory baseline order or reserved tuning, ensemble or confirmation slots. The legacy deterministic profile retains its twelve-experiment policy. See [experiment protocol](experiments.md) and [offline baselines](offline-baselines.md).
