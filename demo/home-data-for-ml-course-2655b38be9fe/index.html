Preserved execution, explicit boundaries

The original run files were moved from artifacts/runs/ unchanged. Their historical absolute paths remain in the snapshots. This report and the compact metrics are derived summaries; the manifest records checksums for audit. No new training or submission was performed while preparing this demo.

Raw competition input CSVs and credentials are not copied here. Individual OOF labels/predictions and the original per-row target chart remain local and Git-ignored. Default verification checks shareable outputs; audit.py verify --full additionally verifies retained private files when available. The saved checkpoint supports optional inference with matching official data and the recorded package environment.
